# CombinePDF

A simple .NET library to combine multiple PDF files into a single PDF document.

## Features

- Drag and drop or upload multiple images or PDF files.
- Combine files into a single PDF document.
- Save the combined PDF.

## Installation

- Publish the project.  
- Zip the contents of the `publish` folder.
- Unzip the contents to your desired location.
- Run the executable file to start the application.
